# bazar

Учебный маркетплейс на Next.js (App Router) с UI-китом `@whiteoligator/drill-kit`.

## Commits and PRs

Do not add Claude attribution to commits or PR descriptions: no `Co-Authored-By` trailer and no `Claude-Session` link. Commits carry only the repo owner as author.

## Next.js

Версия Next здесь новее, чем в обучающих данных: перед кодом сверяйтесь с `node_modules/next/dist/docs/` (см. AGENTS.md).
